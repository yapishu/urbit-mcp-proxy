## urbit mcp proxy

- proxy an arbitrary number of other mcp servers through a single endpoint on your ship, including %mcp on the same ship
- use dumb proxy mode, or insert an openapi mcp schema to dynamically generate the mcp tool calls for your llm
- connect an oauth provider to insert into the proxied mcp requests.
